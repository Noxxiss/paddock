# Svelte + Leaflet for the mobile-first frontend

The frontend is built with Svelte and Leaflet (with Leaflet.draw). Svelte compiles to tiny vanilla-JS bundles — critical for low-connectivity environments — and needs no runtime framework. Leaflet is significantly smaller than MapLibre GL JS (~40 KB vs ~200 KB gzipped) while providing all the map interaction and drawing capabilities needed for farm tasks. Both are plain JS, no TypeScript wrapper needed.
